Project Setup (Python env, requirements, .env, first run)

STEP 1: Create Project Folder

mkdir folder-name
cd folder-name

STEP 2: Install uv

pip install uv
# OR
pip3 install uv

uv --version

STEP 3: Create Virtual Environment

uv venv
source .venv/bin/activate (for Mac/Linux)
.venv\Scripts\activate (for windows)

STEP 4: Install Required Packages

uv pip install -r requirements.txt

STEP 5: Setup .env file

STEP 6: Create Basic Folder Structure

mkdir core detectors services static ml_models - If not install then run - mkdir core, detectors, services, static, ml_models
mkdir services/auth services/coaching services/config services/persistence services/state services/tracking services/ui services/vision - X
use - mkdir services/auth, services/coaching, services/config, services/persistence, services/state, services/tracking, services/ui, services/vision

Windows::

type nul > core\__init__.py
type nul > detectors\__init__.py
type nul > services\__init__.py
type nul > ml_models\__init__.py
type nul > services\vision\__init__.py

Note::- If not installed then use:- 

New-Item -ItemType File -Force core\__init__.py
New-Item -ItemType File -Force detectors\__init__.py
New-Item -ItemType File -Force services\__init__.py
New-Item -ItemType File -Force ml_models\__init__.py
New-Item -ItemType File -Force services\vision\__init__.py

For Verify::-  tree /F

STEP 7: Add main.py

import streamlit as st

st.set_page_config(page_title="AI GYM Coach")

st.title("AI Real-time GYM Coach")
st.write("Setup successful!")

Python: Select Interpreter
Python 3.11.13(AI-Realtime-GYM-Coach-v2)

run:-

uv run streamlit run main.py
